# Stuart Parkhurst

### Research physicist · Data science lead · Applied AI and simulation

I work at the intersection of physics, machine learning, and software
engineering. I build tools that connect research ideas with practical
systems—from data analysis and simulation to AI orchestration and
self-hosted infrastructure.

## What I'm building

My main project is **Tenet**, a platform I’m developing for coordinating
AI agents, tools, context, memory, and model serving across personal
and organizational environments.

My current focus includes:

- Multi-agent workflows, context management, and agent memory.
- Local LLM serving, evaluation, and GPU infrastructure.
- Reinforcement learning and simulation-driven experimentation.
- Reliable deployment, observability, and developer tooling.
